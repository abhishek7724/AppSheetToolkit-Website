Privacy Policy

Clear information about how AppSheet Toolkit handles AppSheet configuration and local analysis data.

Last updated: September 2, 2026

Privacy summary

AppSheet Toolkit reads supported AppSheet configuration only when the user initiates Toolkit functionality. AppSheet configuration, snapshots, comparisons, App Intelligence analysis, App Health findings, and generated technical documentation are processed locally in the browser and are not transmitted to the developer or third-party servers.

1. Overview

AppSheet Toolkit is a browser extension that helps users extract, inspect, compare, analyze, and document supported AppSheet application configuration. Supported configuration includes Tables, Columns, Slices, Views, Actions, Automation Bots, Events, Processes, and supported Task settings. The extension can also create Complete App Snapshots and use them for local Snapshot Comparison, App Intelligence, App Health, and Technical Documentation.

2. Information handled

To provide its core functionality, AppSheet Toolkit handles website content from supported AppSheet editor pages when the user explicitly initiates an extraction or related Toolkit action. This may include application configuration such as table and column names, expressions, validation settings, references, view settings, actions, automation configuration, and supported task settings. Toolkit does not use this information for advertising, profiling, credit decisions, or purposes unrelated to its user-facing AppSheet functionality.

3. AppSheet configuration

The extension reads AppSheet configuration visible or accessible within the AppSheet editor as needed to complete the user-requested operation. Depending on the selected scope, Toolkit may expand editor items or navigate between configuration areas. The resulting metadata is used to create requested exports and local analysis results.

4. Local processing

Extraction, comparison, dependency and impact analysis, App Health analysis, and technical documentation generation occur locally inside the user's browser. AppSheet Toolkit does not upload or transmit extracted AppSheet configuration or generated analysis results to the developer or third-party servers.

5. Local storage and generated files

AppSheet Toolkit does not maintain a cloud database for extracted AppSheet configuration. Generated export files are saved to the user's device according to normal browser download settings. Toolkit may use local browser storage, including IndexedDB, to pass or retain the most recent locally generated comparison, analysis, health, or documentation result between Toolkit pages. This storage remains on the user's device and can be removed through normal browser data controls.

6. Personal information, analytics, and tracking

The extension does not require a Toolkit account and does not include advertising, analytics scripts, tracking pixels, or behavioural tracking tools. AppSheet configuration may itself contain values entered by the application owner, so users should review exported files before sharing them outside their own environment.

7. Sharing and sale of information

AppSheet Toolkit does not sell, rent, or transmit extracted AppSheet configuration or generated analysis data to third parties.

8. Permissions

The extension requests only the permissions required for its current functionality. activeTab is used when the user interacts with Toolkit on an active AppSheet editor page. sidePanel displays the Toolkit interface alongside AppSheet. Host access is limited to https://*.appsheet.com/* so Toolkit can read supported AppSheet configuration and does not receive host access to unrelated websites.

9. Chrome Web Store Limited Use

The use of information received through Chrome APIs complies with the Chrome Web Store User Data Policy, including the Limited Use requirements. AppSheet configuration is used only to provide and improve the user-facing functionality of AppSheet Toolkit.

10. Third-party services

AppSheet is a third-party product owned by Google. AppSheet Toolkit is an independent extension and is not affiliated with or endorsed by Google.

11. Changes to this policy

This policy may be updated when the extension's features or data practices change. The latest version will remain available on this page.

12. Contact

Questions about this policy can be submitted through the support page.
