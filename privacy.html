Privacy Policy

Clear information about how AppSheet Toolkit handles data.

Last updated: August 7, 2026

Privacy summary

AppSheet Toolkit processes AppSheet configuration metadata locally in your browser. Extracted metadata is not transmitted to the developer or to external servers.

1. Overview

AppSheet Toolkit is a browser extension that helps users extract AppSheet application metadata, including tables, columns, slices, and views, into JSON and CSV files. The extension is designed to perform its processing locally in the user's browser.

2. Information handled

AppSheet Toolkit does not transmit personal information, account credentials, passwords, payment information, browsing history, or analytics data to the developer or to external servers. The extension does not require users to create an account.

3. AppSheet metadata

When a user explicitly starts an extraction, the extension reads AppSheet configuration metadata visible within the AppSheet editor, including table, column, slice, and view information. This metadata is used only to generate the JSON or CSV export requested by the user.

4. Local processing

Metadata processing and file generation occur locally inside the browser. AppSheet Toolkit does not upload or transmit extracted AppSheet metadata to servers operated by the developer or to third parties.

5. Data storage

AppSheet Toolkit does not maintain a cloud database for extracted metadata and does not store exported AppSheet metadata on an external server. Files generated by the extension are created locally and downloaded directly to the user's device according to the browser's download settings.

6. Analytics and tracking

The extension does not include advertising, analytics scripts, tracking pixels, or behavioural tracking tools.

7. Sharing of information

AppSheet Toolkit does not sell, rent, or share extracted AppSheet metadata or personal information with third parties.

8. Permissions

The extension requests only the permissions needed to operate on supported AppSheet editor pages. These permissions allow the user to open the Toolkit side panel, access the active AppSheet editor page after user interaction, read the configuration metadata needed for an extraction, and generate the requested files locally.

9. Third-party services

AppSheet is a third-party product owned by Google. AppSheet Toolkit is an independent extension and is not affiliated with or endorsed by Google.

10. Changes to this policy

This policy may be updated when the extension's features or data practices change. The latest version will remain available on this page.

11. Contact

Questions about this policy can be submitted through the support page.
