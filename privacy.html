Privacy Policy

Clear information about how AppSheet Toolkit handles data.

Last updated: August 8, 2026

Privacy summary

AppSheet Toolkit does not collect, transmit, sell, or share personal information.

1. Overview

AppSheet Toolkit is a browser extension that helps users extract AppSheet table, column, slice, and view metadata into JSON and CSV files. The extension is designed to perform its processing locally in the user's browser.

2. Information collected

AppSheet Toolkit does not collect personal information, account information, passwords, payment information, browsing history, or analytics data. The extension does not require users to create an account.

3. AppSheet metadata

The extension reads table, column, slice, and view configuration metadata visible within the AppSheet editor when a user explicitly starts an extraction. To collect slices and views, the extension may expand list items or switch the editor to another configuration screen and return to the original screen once it is finished. This metadata is used only to generate the JSON or CSV files requested by the user.

4. Local processing

Metadata processing and file generation occur locally inside the browser. AppSheet Toolkit does not upload extracted metadata to an external server operated by the developer.

5. Data storage

AppSheet Toolkit does not maintain a cloud database and does not store extracted metadata on an external server. Files generated by the extension are downloaded directly to the user's device according to the browser's download settings.

6. Analytics and tracking

The extension does not include advertising, analytics scripts, tracking pixels, or behavioural tracking tools.

7. Sharing of information

AppSheet Toolkit does not sell, rent, or share user information with third parties.

8. Permissions

The extension requests access only to the permissions required to operate on AppSheet pages, open its side panel, communicate with its content script, and generate files requested by the user. Host access is limited to appsheet.com addresses, so the extension cannot read any other website.

9. Third-party services

AppSheet is a third-party product owned by Google. AppSheet Toolkit is an independent extension and is not affiliated with or endorsed by Google.

10. Changes to this policy

This policy may be updated when the extension's features or data practices change. The latest version will remain available on this page.

11. Contact

Questions about this policy can be submitted through the support page.
