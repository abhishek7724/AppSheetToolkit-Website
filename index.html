FAQ

Questions before installing?

The essentials, without the fine print.

Does AppSheet Toolkit send my AppSheet configuration anywhere?

No. AppSheet configuration is processed locally in your browser and is not transmitted to the developer or third-party servers.

What can I extract?

Toolkit supports Tables and Columns, Slices, Views, Actions, Automation Bots, Events, Processes, supported Tasks, and a Complete App Snapshot containing the supported configuration in one JSON file.

What is the Analyze tab?

Analyze contains Snapshot Comparison, App Intelligence, App Health, and Technical Documentation. These tools work from Complete App Snapshot files and run locally in your browser.

What does App Intelligence do?

It builds a static dependency model from the snapshot so you can explore what a component uses, what uses it, and discovered direct or downstream impact. It is an analysis aid, not a runtime guarantee.

What does App Health do?

App Health identifies static review candidates such as unresolved references, maintainability signals, duplicate-like configuration, and potentially unused components. Findings are intentionally presented for developer review rather than automatic deletion.

Can Toolkit generate technical documentation?

Yes. Technical Documentation can generate structured HTML and Markdown covering the application summary, data model, configuration, automation, dependencies, App Health findings, and an optional baseline comparison.

Can I export JSON and CSV together?

Yes for regular component exports. Complete App Snapshot is generated as structured JSON because it is also the input for the Analyze tools.

Is this an official Google product?

No. AppSheet Toolkit is an independent third-party extension and is not affiliated with or endorsed by Google.
