FAQ

Questions before installing?

The essentials, without the fine print.

Does AppSheet Toolkit collect my data?

No. The extension does not use analytics, tracking, or an external data-storage server.

Can I extract Slices, Views, Actions, and Automation Bots too?

Yes. v1.7.7 supports Tables and Columns, Slices, Views, Actions, and Automation Bots, including supported Events, Processes, and Tasks.

What is Complete App Snapshot?

It captures Tables, Columns, Slices, Views, Actions, and Bots together in a single structured JSON file so the application can be documented, compared, or analyzed as one configuration snapshot.

Can I export JSON and CSV together?

Yes for regular component exports. Complete App Snapshot is intentionally generated as one structured JSON file.

What happens if I cancel halfway?

Nothing is written. Files are only created once a full run completes, so a cancelled run never leaves a partial export behind.

Is this an official Google product?

No. AppSheet Toolkit is an independent third-party extension and is not affiliated with or endorsed by Google.
